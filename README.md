# ServerDownloader

Серверный Fabric-мод для Minecraft **1.21.11**. По команде копирует ВСЮ
корневую папку сервера (мир/миры, `config/`, сам `mods/` со всеми модами,
`server.properties`, `whitelist.json`, `ops.json` и т.д.) в новую папку
внутри `mods/serverdownloader_backups/<дата_время>/`.

Это **не сетевая скачка**, а локальное копирование файлов на той же
машине, где стоит сервер — мод ставится на каждый сервер, где вам нужна
такая кнопка бэкапа.

## Как вызвать

- Команда: `/server download`
- Или сообщение в чат: `.server download`

В обоих случаях нужны права оператора уровня **4** (высший, как у
владельца сервера — `/op <ник>` даёт по умолчанию уровень 4).

## Сборка

1. Установите **JDK 21**.
2. **Перед первой сборкой** откройте `gradle.properties` и сверьте
   значения `loader_version`, `loom_version`, `fabric_version` с
   актуальными на https://fabricmc.net/develop — эта экосистема
   обновляется чаще, чем раз в неделю, и то, что было правильным на
   момент написания мода, может устареть. Проще всего: сгенерировать
   пустой шаблон мода на том же сайте и скопировать оттуда актуальные
   числа в этот `gradle.properties` (код трогать не нужно).
3. В корне проекта:
   ```
   ./gradlew build
   ```
   (на Windows — `gradlew.bat build`)
4. Готовый файл появится в `build/libs/serverdownloader-1.0.0.jar`.
5. Положите этот `.jar` в папку `mods/` на **Fabric-сервере** (не
   Bukkit/Spigot/Paper — это другая экосистема, этот мод с ней не
   совместим) с установленными:
   - Fabric Loader (соответствующей версии)
   - Fabric API (нужен обязательно — мод от неё зависит)

## Важные оговорки

- Мод работает только на **Fabric**-серверах. Для Bukkit/Spigot/Paper
  (где используются "плагины" в привычном смысле) нужен был бы
  отдельный плагин на другом API — текущий код для них не подойдёт.
- Копируется абсолютно всё содержимое корня сервера, кроме самой папки
  `mods/serverdownloader_backups` (чтобы бэкапы не копировали сами
  себя и не раздувались бесконечно при повторных запусках).
- Копирование идёт в отдельном потоке, не блокируя тики сервера, но
  при большом мире может занять ощутимое время и место на диске —
  бэкапы никуда не удаляются автоматически, чистить `mods/serverdownloader_backups/`
  нужно вручную.
- Один "занятый" файл (например `session.lock` активного мира) не
  прерывает копирование целиком — такие файлы просто пропускаются,
  о чём будет сказано в итоговом сообщении.
